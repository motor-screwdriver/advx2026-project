The `app/` directory follows Expo Router's file-based routing convention: each `.tsx` file is a route whose default export is a thin React component that renders a corresponding screen from `../src/screens/*`. The root `_layout.tsx` sets up the global shell — it waits for game fonts via `useGameFonts`, wraps all screens in `GameProvider` (from `../src/ui/useGame`), configures a `Stack` navigator with hidden headers and a theme-driven background color, and applies a light status bar. The `index.tsx` entry performs conditional redirection: if `state.onboardingDone` is false, it redirects to `/onboarding`; otherwise it renders `HomeScreen`. All other route files (`heroes.tsx`, `inventory.tsx`, `settings.tsx`, `tutorial.tsx`, `onboarding.tsx`, etc.) are one-line pass-throughs delegating to their `*Screen` counterparts in `src/screens/`, keeping routing concerns separate from UI logic.
