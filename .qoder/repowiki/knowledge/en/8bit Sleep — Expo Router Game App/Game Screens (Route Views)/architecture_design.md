Each file is a single-screen React component exported as a default named function (e.g. `HomeScreen`, `OnboardingScreen`, `DeathScreen`). Screens are route views consumed by expo-router; navigation uses `useRouter()` with `router.push`/`router.replace`/`router.dismissTo` against string paths like `/onboarding`, `/hero-ceremony`, `/death`. All screens consume global game state and actions through the `useGame` hook from `../ui/useGame`, keeping UI pure and data centralized. Presentation is built exclusively from reusable UI primitives in `../ui/*` (`Screen`, `PixelButton`, `PixelPanel`, `HeroSprite`, `SceneBanner`, etc.) and themed via `../ui/theme` and localized via `../ui/strings`. Audio side-effects are triggered through `../systems/audio` (`playMusic`, `playSfx`). The `DebugMenu` is a dev-only overlay gated by `__DEV__` and the `FLAGS.artGallery` flag, exposing all routes plus debug presets. There is no internal routing or shared logic between screens — dependency direction is one-way: screens → ui primitives → systems/audio → contracts/types.
