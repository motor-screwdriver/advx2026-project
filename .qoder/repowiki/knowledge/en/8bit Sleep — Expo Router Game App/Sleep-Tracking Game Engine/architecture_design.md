The module is a collection of pure-function modules organized by game domain: `turn.ts` is the single orchestration entry point (`applyNightTurn`) that composes `night.ts` (scoring), `levels.ts` (HP/streak modifiers), `artifacts.ts` (consumable/equipment logic), `chest.ts` (loot tables), `hero.ts` (hero assignment from a 3×3 grid based on bedtime/duration), `resurrection.ts` (death/cooldown), and `time.ts` (night-line minutes, date stamps). All modules import shared types from `../contracts/types` and never import from UI code — enforced by eslint-plugin-boundaries. State is immutable: each function returns a new `GameState` or derived result rather than mutating inputs. Cross-module dependencies are one-directional: `turn.ts` depends on all others; `artifacts.ts` depends only on `levels.ts` and `night.ts`; `resurrection.ts` depends only on `time.ts`. Tests live in `__tests__/` alongside source files and use fixtures for deterministic RNG injection.
