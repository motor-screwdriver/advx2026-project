Single-entry bootstrap in `index.tsx` (`initSystems`, `SystemsLayer`) wires all integrations to the global `useGameStore`: it subscribes to store changes, listens to `AppState` events, and mounts the floating `DemoPanel` plus the off-screen `EinkCardHost`. Each integration is a self-contained module with its own persistence layer (`AsyncStorage` keys like `8bit-sleep/eink-config`, `8bit-sleep/notifications-enabled`) and degrades silently when unavailable. The e-ink pipeline composes three files: `einkConfig.ts` (config + `parseDeviceId`), `einkCard.tsx` (off-screen React render captured via `react-native-view-shot`), and `eink.ts` (debounced HTTP POSTs to `dot.mindreset.tech`). Notifications are lazy-loaded via `require('expo-notifications')` only on native builds, skipping Expo Go and web. NFC uses the same lazy-require pattern against `react-native-nfc-manager`. Pure scheduling math lives in `scheduleMath.ts` (no framework imports, jest-safe) and is reused by both notifications and demo logic. Feature flags from `../contracts/flags` gate optional modules (`FLAGS.eink`, `FLAGS.healthSync`).
