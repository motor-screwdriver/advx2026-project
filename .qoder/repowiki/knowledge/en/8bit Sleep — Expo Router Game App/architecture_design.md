The root is a single pnpm workspace (pnpm-workspace.yaml) that declares one package — itself — so all TypeScript/JS code lives under this directory and resolves via shared node_modules. Expo Router bootstraps the app through `expo-router/entry` (package.json main), with file-based routes in `app_routes` driving screen components under `screens`. Cross-cutting state flows from `state_management` (Zustand + AsyncStorage) into `game_engine` (pure TS scoring/progression logic), while `systems` plugs in e-ink, notifications, NFC, and a demo panel against the same store. The `ui_components` library supplies themed pixel-art primitives and mini-game screens consumed by `screens`. Metro is customized in `metro.config.js` to force zustand's CJS build on web, and `tsconfig.json` extends expo's base with strict mode plus jest types. All modules share the same ESLint/Prettier/Husky/Lint-staged configuration at the root, enforcing uniform linting, formatting, and pre-commit checks across every child module.
