Requires `PIXELLAB_SECRET` set as an environment variable or in a repo-root `.env` file (see `.env.example`) before any PixelLab commands. Typical workflow: run `python3 tools/pixellab_gen.py <command>` for one-off generations, `python3 tools/pixelate.py <input> --section <section> --grid WxH [--frames N] [--outline|--one-bit]` to bake assets into `assets/<category>/` and update the manifest, and `python3 tools/generate_audio.py` to rebuild all WAVs under `assets/audio/`. The batch pipeline `tools/pixellab_batch.py` runs three phases (`api`, `build`, `switch`) to regenerate every visual asset through PixelLab and swap `app.json` + manifest paths to the `assets/pixellab/` tree.
