Pure Python with PIL/Pillow for image processing, stdlib `wave`/`json`/`math` for audio synthesis (square/triangle oscillators, 15-bit LFSR noise, ADSR envelopes at 22050 Hz mono u8 PCM). External dependency is the PixelLab REST API (`https://api.pixellab.ai/v1`) accessed via `urllib.request`. The manifest generator emits TypeScript with `as const satisfies Record<...>` types consumed by the UI.
